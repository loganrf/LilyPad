Forgot or never saw the password? {% if env_password %}

The password is set by the LILYPAD_ADMIN_PASSWORD environment variable in your docker-compose.yml (or .env file).

{% else %}

On first start LilyPad generated a password, printed it in the container log and saved it to INITIAL_ADMIN_PASSWORD.txt in the data volume:

docker compose logs lilypad | grep -i password
docker compose exec lilypad cat /data/INITIAL_ADMIN_PASSWORD.txt

To reset it: docker compose exec lilypad python -m app.cli reset-password (prints a new one). See the README.
